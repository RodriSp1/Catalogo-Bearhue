# Catálogo de BearHue

Catálogo web y cotizador de pedidos diseñado para la tienda de peluches **BearHue** (`@bear.hue_`). Permite a los clientes explorar productos, armar un carrito y generar una nota lista para enviar por mensaje directo en Instagram.

## Funcionalidades
- Filtrado de productos por categoría (Caricaturas, Animales, Gigantes).
- Carrito interactivo con control de cantidades y cálculo automático del total.
- Generador de nota de pedido con campo opcional para nombre o dedicatoria.
- Copiado automático al portapapeles y redirección directa al DM de Instagram (`@bear.hue_`).

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Ejecución local
1. Clona o descarga este repositorio.
2. Asegúrate de incluir las imágenes de los productos y el logotipo en la carpeta raíz.
3. Abre el archivo `index.html` en tu navegador.
